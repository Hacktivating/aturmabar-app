# Authentication UI review

The login page now uses a centered minimalist card with AturMabar branding, language/theme controls, a short `Welcome back` eyebrow, login title, two fields, forgot-password link, primary login action, and registration link. The previous hero headline, description, benefit cards, and footer message are gone.

The forgot-password page now uses the same shell and presents a clear title, one concise explanation, an email field, `Send reset link`, and `Back to login`. In Indonesian the equivalent copy renders as `Atur ulang kata sandi`, `Kirim tautan reset`, and `Kembali ke masuk`. The stale raw keys `forgot_pwd`, `send_reset`, and `back_login` are no longer used.
